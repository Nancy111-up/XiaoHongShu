## 标题公式

### 公式 A：痛点 + 解决方案暗示
```
「通勤包太重？这只不到一杯奶茶重」
「为什么你的穿搭总是差一点高级感」
```

### 公式 B：数字 + 具体场景
```
「3件单品搞定一周通勤不重样」
「上班第1年 vs 第3年的包包进化史」
```

### 公式 C：反常识/反差
```
「越简单的穿搭越显贵，前提是你做对这1点」
「不买大牌也能穿出高级感的方法」
```

---

## 正文结构

### 黄金三段式
1. **金句开场** — 1-2句话，击中痛点或制造好奇
2. **干货铺陈** — 2-3段分点叙述，每段不超过3行
3. **软植入收尾** — 自然过渡到产品，语气克制

---

## 标签策略
- 品类标签 1-2个：#通勤穿搭 #法式风格
- 场景标签 1-2个：#上班穿什么 #约会穿搭
- 品牌/情感标签 1个：#独立设计师 #质感生活

---

## 语气基线
- 像分享发现，不像推销产品
- 多用「我发现」「最近试了」「意外好用」
- 少用「推荐」「必入」「一定要买」
